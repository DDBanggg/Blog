# Roadmap

## Phase 0: Project foundation — Hoàn thành

- Mục tiêu: tạo nền tảng Astro, công cụ chất lượng và tài liệu.
- Deliverables: cấu hình dự án, Content Collection, trang tạm thời, Git và docs.
- Exit criteria: các lệnh kiểm tra thành công và initial commit được tạo.

## Phase 1: Content model and Markdown migration — Hoàn thành

- Mục tiêu: chuẩn hoá và chuyển 48 câu hỏi vào collection.
- Deliverables: 48 Markdown hợp lệ, metadata và media liên quan.
- Exit criteria: mọi bài qua schema và tuân thủ Content Guide.

## Phase 2: Blog layout and navigation — Chưa bắt đầu

- Mục tiêu: xây layout đọc bài và điều hướng dùng chung.
- Deliverables: header, footer, dark mode hoàn chỉnh, điều hướng cơ bản.
- Exit criteria: responsive và điều hướng bàn phím tốt.

## Phase 3: Interview index and article pages — Chưa bắt đầu

- Mục tiêu: xuất bản danh sách và trang chi tiết.
- Deliverables: `/interview/`, `/interview/[slug]/`, category/tag, TOC, previous/next.
- Exit criteria: toàn bộ 48 bài truy cập đúng route.

## Phase 4: Search, SEO and RSS — Chưa bắt đầu

- Mục tiêu: cải thiện khám phá và chia sẻ nội dung.
- Deliverables: full-text search, metadata SEO, sitemap và RSS.
- Exit criteria: kiểm tra index/search và metadata đạt yêu cầu.

## Phase 5: Quality assurance and Cloudflare deployment — Chưa bắt đầu

- Mục tiêu: kiểm thử và phát hành static site.
- Deliverables: QA checklist, cấu hình Cloudflare Pages, production deployment.
- Exit criteria: build production và website hoạt động trên Cloudflare Pages.

## Phase 6: Future improvements — Chưa bắt đầu

- Mục tiêu: đánh giá các cải tiến sau MVP.
- Deliverables: backlog ưu tiên dựa trên phản hồi.
- Exit criteria: roadmap hậu MVP được rà soát.
